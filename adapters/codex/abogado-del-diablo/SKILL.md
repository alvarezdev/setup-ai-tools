# Abogado del Diablo para Codex

Lee primero `upstream/SKILL.md` y conserva sus ocho ángulos, tono y formato de
salida. Para ampliar un ángulo concreto, consulta
`upstream/references/angulos.md`.

Traduce las capacidades descritas upstream así:

| Necesidad | En Codex |
| --- | --- |
| Mapear o leer el proyecto | lectura local y `rg` |
| Ataque profundo en paralelo | subagentes solo si están disponibles y autorizados |
| Casos reales comparables | búsqueda web cuando esté disponible |
| Falta información crítica | una pregunta directa al usuario |

No asumas nombres de herramientas de Claude. Si una capacidad no está disponible,
continúa con la mejor crítica posible y declara esa limitación sin inventar fuentes.
