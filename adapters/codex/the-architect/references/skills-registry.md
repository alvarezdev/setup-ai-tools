# Codex Capability Registry

Use only capabilities available in the active environment; do not require a
named command. Describe the capability and the build step it supports.

| Capability | Use in the blueprint when |
| --- | --- |
| Documentation or web research | A technology choice needs current evidence. |
| UI and visual-design guidance | The target has a frontend or brand surface. |
| Browser automation | Reference-site analysis or end-to-end testing is in scope. |
| Code exploration and test execution | The build order needs repository discovery or verification. |
| Specialized installed skills | A listed skill clearly helps a specific build step. |

If a capability is absent, give a practical manual alternative or proceed with a
stated assumption. Never make blueprint generation depend on it.
